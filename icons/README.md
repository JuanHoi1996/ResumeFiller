# ResumeFiller icons

- **Source:** `svg/icon.svg` — full-bleed blue tile + center-pivot oblique **R**
- **Chrome PNG:** `active/icon{16,32,48,128}.png` (referenced in `manifest.json`)

Regenerate after editing SVG:

```bash
python icons/export_svg_to_png.py
```

Then reload the extension at `chrome://extensions`.
